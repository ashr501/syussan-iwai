# SNS素材: 2人目に服を贈るなら何サイズ？80cmが選ばれる理由と季節ズレの注意点

## X投稿文(断定を避ける・2〜3案から選択)

### 案1(結論先出し型)
2人目の出産祝いに服を贈るなら、新生児サイズよりも80cm前後が使われやすい傾向があります。
上の子のお下がりがくたびれてくるのが、ちょうど1歳ごろ。
サイズと季節ズレの考え方をまとめました。
https://honne-catalog.com/articles/second-child-clothes-size.html

### 案2(あるある共感型)
出産祝いでもらった新生児サイズの服、袖を通す前にサイズアウトした…という声は少なくありません。
2人目ならなおさら、お下がりで足りていることも。
服を贈るなら何サイズがいいか、本音ベースで整理しました。
https://honne-catalog.com/articles/second-child-clothes-size.html

### 案3(豆知識型)
ベビー服の80cmを着るのは約1年後。
「生まれた季節と同じ季節に着る」と覚えておくと、季節ズレの失敗が減ります。
2人目の出産祝いに服を選ぶときのポイントをまとめました。
https://honne-catalog.com/articles/second-child-clothes-size.html
